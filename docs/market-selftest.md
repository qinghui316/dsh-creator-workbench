# Stage A 本地自测清单

目标：Windows x64，DSH Desktop 0.12.1 / Harness 0.2.1-rc.2。工作台 dsh-creator-workbench 0.1.0。
本清单说明验收要求；具体包哈希、命令退出状态、安装记录和截图保存在项目 Harness 的 windows-video-import Change 中。历史证据不代替后续版本复测。

| 检查项 | 必须保留的证据 |
| --- | --- |
| 代码、构建与架构 | 当前工作区 pnpm check 日志；依赖 AST 检查结果 |
| 文件保护 | 取消、失败、无权限、并发同名、中文/空格/长路径回归 |
| 视频选择 | 单视频、多视频、相对文件名保存、选中文件缺失、资料库隔离 |
| 预览 | 实际播放；Range 请求；文件替换和消失时服务继续可用 |
| 包 | 实际 tgz 的入口、插件声明、文件清单、敏感文件与构建一致性 |
| 本机安装 | 配套安装入口、实际安装路径、安装产物与源码构建的哈希 |
| 已安装的工作台 | 创作工作台条目、本地标识、版本、运行状态；原工作台并存 |
| 左侧入口 | 切换菜单自动出现创作工作台 |
| 无会话业务 | 选资料库、新建内容、导入、当前视频选择与播放 |
| 所属会话 | 主动打开原生会话，内容目录和归属一致；不自动发送提示词 |
| 布局 | 侧栏展开/收起、窄窗口、真实长度中英文内容、公共入口 |
| 重开 | 再次加载，内容、当前视频与会话关联仍在 |

分别报告安装成功、加载成功与业务验收结果。宿主兼容性告警、未配置模型或未实测场景必须另列，不以单元测试替代真实界面记录。
封面自主服务、多平台草稿和公众号真实验收属于后续阶段。
