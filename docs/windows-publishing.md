# Windows 发布与公众号：0.4.0 使用说明

本轮 Change：`windows-publishing-wechat`，版本 `0.4.0`。安装、加载和各平台业务验收分别记录，最终包哈希、安装字节与界面证据保存在 Change 验证记录中。公众号远端上传和视频号按用户要求延期，不计为本轮通过。

## 使用入口

原来的左右分栏、历史内容侧栏和「概览 → 视频 → 脚本 → 字幕 → 文章」保持。

- 历史内容条目旁的“删除”经确认后将项目移出列表，目录、文件和会话历史保留；会话归档与空工作区清理通过宿主公开接口完成。删除后不显示回收列表；在“新建内容 → 使用已有目录”明确重新加入，优先恢复原会话。
- “打开项目对话”、封面和文章按钮进入该项目已有目录的工作区，优先复用已有会话，不再跳到资料库父目录。其他会话仍可通过明确的项目和制作请求处理同一期内容。

- 「数据与设置 → 发布平台」准备 Windows 运行环境，在 Ego 中登录，再检查并连接实际账号。每个平台关联一个当前账号，换号需要明确确认，旧任务仍属于原账号。
- 本期概览的「视频发布 → 准备上传」使用明确选中的视频、封面、标题、简介和话题。确认本次原创属性后准备平台草稿。上传不要求先写脚本或生成字幕；最终发表由用户完成。
- 「字幕」可导入已有 SRT/ASS，或使用火山录音文件极速识别。Key 在设置中保存；目前按两小时、提取音频 100MB 预检。
- 「文章」准备原生 Agent 请求，由用户发送。Agent 读取匹配的视频转写和真实截图，使用随包提供的 WeWrite 写作、规则和定向检查，保存正文新版本并生成排版 HTML。文章页默认展示成品，“打开 HTML 成品”可打开独立文件；Markdown 留作可编辑源稿。
- 「数据与设置 → 公众号」填写 AppID 与 AppSecret，或明确导入本机配置。文章页可预览、创建或更新公众号草稿，读取确认后记录提交快照。
- 「发布状态与数据 → 同步数据」只手动执行。先按当前账号发现候选，用户确认关联后直接按平台标识精确读取；同账号、同作品的真实结果才更新为已发表。未知、未找到、无权限和真实数值零分别处理。

凭据经 Harness 专用服务保存。浏览器 Cookie、服务 Key、公众号 Secret 和访问令牌不进入 Agent、普通设置接口或安装包。

## 浏览器与恢复

Ego 是用户确认的 Windows 浏览器。检查账号的临时页完成后关闭；上传编辑页交还给用户继续操作。后台不使用时不保留 Agent 控制。

任务固定资料目录、视频哈希、封面、材料和账号；继续使用原任务，不创建另一份上传。用户接管或浏览器权限提示出现时停止操作。用户处理后，在发布设置点击“继续浏览器操作”，再返回原任务点击“继续原任务”。提示可能已消失时，以重新观察到的页面为准。重新打开设置分组会读取最新状态，不覆盖未保存的输入。

普通上传对相同内容目录、平台、账号、视频及材料返回已有任务，包含中断、受阻或草稿就绪记录。更换材料也会先提示检查原草稿；确实需要另一份时展开“需要另外一份草稿”，明确另建。界面和 Agent 共用同一准入锁，重复点击和并发确认不会静默新增上传。

按钮导航使用当前项目的目录，并复用已有会话；连续点击不会重复创建会话。宿主按目录解析已有工作区。会话信息用于导航和任务显示，不限制 Agent 从其他会话处理同一请求；工具仍核对项目目录、视频和实际任务。用户原有草稿和附件不被覆盖。已有工作区及历史会话不直接改写或搬移。

文章截图按视频、字幕时间轴和抽帧参数登记缓存，复用前校验文件及解码。中断后补齐缺失项；已完整生成的临时图片可以恢复，损坏的已有产物保留核对，不覆盖全部截图。本地 HTML 预览不占用或修改正在提交的公众号草稿任务。

锁定版上传 Skill 尚未填写小红书正文，工作台用独立适配补充：核对原视频和标题，仅向空白正文插入简介，保留原生话题节点；已有不同文字不覆盖。独立回读通过前不报告完整就绪。

抖音适配保留已有草稿；在完整发布表单中核实未提供跨平台同步时记录“未提供”，不把缺少控件当作开关已关闭。双封面通过实际图片入口和按钮操作，核对画幅后再上传。兼容层遇到交还控制信号后，本轮不再调用浏览器，即使参考脚本捕获了该异常。

## 转写服务开通

当前使用 **豆包录音文件识别极速版**，资源为 `volc.bigasr.auc_turbo`，由工作台指定。

1. 在[服务状态](https://console.volcengine.com/speech/service/10012)核对“录音文件识别大模型 → 极速版”。本机实际发现新版开通管理只列出流式识别，极速版在旧版控制台中；不要因新版未显示就重复开通。
2. 已有正式服务且时长包运行中时，从同一项目的 [API Key 管理](https://console.volcengine.com/speech/new/setting/apikeys)获取 Key。
3. 在工作台“数据与设置 → 语音转文字”保存 Key，再到本期“字幕”页测试。Key 不发到对话里。

开通与 Key 都按项目隔离，详见[官方控制台指引](https://docs.volcengine.com/docs/DoubaoVoice/console-guidance?lang=zh)和[极速版接口说明](https://docs.volcengine.com/docs/DoubaoVoice/recording-file-recognition-lite-http?lang=zh)。本机该服务此前已开通，本轮用用户保存的 Key 完成一次真实转写；服务权限和 Key 可用性均有实际证据。
