# 使用指南

1. 打开左侧「工作台」的切换区域，选择「创作工作台」。
2. 在「数据与设置」选择资料库；也可以首次新建内容时选择。一个内容对应资料库中的一个文件夹。
3. 新建或选中一期内容，在概览或视频页点击「导入视频」选文件，确认导入后的文件名，再点「开始导入」。
4. 导入成功会设为当前视频。目录里有多个既有视频时，从「当前视频」中明确选择。
5. 可以刷新、播放与拖动进度；重新打开后选择仍保留。文件消失时重新选择，工作台不会自动换成其他文件。

导入复制原文件，同名文件不覆盖，修改导入名称后重试。导入进行中可以取消；取消不会移除原文件、已有文件或其他任务产物。MP4/MOV 容器中的个别编码可能无法在 Desktop 播放，文件仍可用外部播放器打开。

基础内容管理不需要会话。需要 AI 协助时，点击「在资料目录开始对话」，选择这一期目录，沿用宿主的 Agent、模型、工具、Skill 与 Jobs。
脚本在 script.md，选题在 topic.md。文章与发布状态展示保留；平台上传和公众号的真实验收在后续阶段分别完成。

视频列表的「从列表移除」只隐藏条目，文件和文件夹保留。可以立即撤销，也可以展开「已移除视频」恢复。移除当前视频会停止预览并清空选择；恢复不会自动替换当前视频。重新加入本期目录内同一文件会恢复原条目，不重复复制；外部同名文件仍按无覆盖导入处理。

## 封面

每种画幅可直接「导入已有封面」，支持 PNG、JPEG、WebP。图片必须符合 3:4、4:3 或 16:9；新版本保留原图，使用版本需要明确选择。点击图片可放大查看。

需要 AI 制作时，先选择当前视频，点击「让 Agent 制作封面」。工作台将请求放入本期原生会话草稿，由你发送；已有草稿会保留，按需点击「追加制作请求」。Agent 读取视频候选画面，完成标题、选帧和提示词后直接生成，再逐张检查。当前 Agent 必须支持看图；缺少独立字幕不阻止制作。

在「数据与设置」配置生图服务根地址（包含服务要求的版本路径，例如 `/v1`）、生图模型，并在下方凭据区保存生图 API Key。服务必须兼容 OpenAI 图片接口；参考画面制作要求图片编辑能力，三种尺寸需由服务支持。工作台不会自动更换服务、改成纯文字制作或裁切图片。

「检查连接」只读取模型列表；「测试生图：1 张，可能计费」才会发起真实图片请求。Key 不进入会话和任务提示。配置变化后重新检查能力。

新生成图片检查前不会替换现有封面。失败时只重试对应画幅；结果未确认时先核对服务端记录，再明确重试，避免重复计费。取消会保留完整成果，重开不会自动重新发送生图请求。

当前本机已实测视频移除/恢复、原生请求草稿、3:4 与 4:3 封面导入及版本选择。真实 Agent 看图、生图服务、三画幅生成和完整界面验收仍待配置与验证，详见 [本轮验证记录](native-covers.md)。

视频字幕是可选资料，不阻止准备封面和发布材料。AI 上传流程默认停在最终发表前，由人确认发表。
