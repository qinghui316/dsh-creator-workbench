# 0.7.2 界面与交互

现有对话分栏、项目列表与详情、七个页签及业务顺序继续使用。

- 顶栏采用紧凑按钮；项目工具与详情标题顶端一致，标题、导航及正文共享内边距。
- 主页面签用自身下划线；平台和设置使用清楚的当前项背景。窄区只滚动所属导航，使当前项保持可见。
- 文章先展示当前版本及阅读内容，常用编辑与发布直接可用；创建、导入及打开HTML成品集中在一层菜单。
- 发布页先选择当前材料，再编辑文案素材；新建与跨平台复制通过材料操作菜单进入。上传缺项可直接定位处理。
- 字幕页合并重复空态，准确显示当前视频的失败；新导入失败时保留已有字幕并说明错误。
- 菜单支持键盘打开、方向键、Esc和Tab；编辑保存、上传快照及草稿保护沿用现有业务能力。

安装、浏览器测量、原生窗口及未验证项分别记录于项目Harness的 workbench-ui-consistency-repair Change，安装成功不代替完整界面验收。
