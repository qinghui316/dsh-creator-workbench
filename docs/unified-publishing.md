# 统一创作与平台发布

一个项目对应一个资料目录。创建时填写标题即可；脚本、文章、视频和图片可以独立制作，也可以互相复用。

## 如何使用

- 左侧直接提出要求，例如“按这个选题写脚本”“写文章并做好配图和公众号排版”“把文章改成小红书多图”。Agent 使用工作台工具保存成果，右侧刷新展示。
- 右侧保留“概览 → 视频 → 脚本 → 字幕 → 文章”。脚本可以编辑并自动保存；文章可以独立写作、导入、选择版本和查看 HTML；概览管理图片和平台发布内容。
- 需要 Agent 的按钮会恢复本项目已有会话并准备请求，由用户发送。已有草稿保留，追加操作明确可见。

## 每个平台单独准备材料

在概览的“发布”中新建发布内容，选择平台与形式，填写文案、选用视频或安排图片顺序。可以复用已有文章，也可以让 Agent 单独改写文案或制作图片。

小红书、抖音使用图片组和独立正文；B站使用文章编辑器导入正文和配图。公众号使用 WeWrite 排版和明确选定的文章封面。HTML 用于文章阅读与排版，图片平台接收自己的文字与图集。

保存后上传的是该版本材料。上传开始时固定账号、正文、图片顺序和文件；随后修改平台文案或预览源文章，不改变正在提交的内容。来源文章有变化时只提示，是否重新采用由用户决定。

图文首图与封面同步选用；选择封面会把它放到第一张，调整首图时封面也随之更新。文章材料保存自己的正文配图路径与顺序，调序或移除只影响该份材料，源文章保持。

小红书视频封面使用3:4；抖音视频封面使用3:4、4:3；B站视频封面使用4:3、16:9。图文默认以图集首图为封面，需在平台结果页核对最终显示。小红书新制作图集默认3:4，已有图片按实际编辑器检查。

## 上传与恢复

“上传并准备草稿”完成后，由用户到平台核对并手动发表。工作台不会点击最后的发表按钮。

中断后使用“检查原任务”或“继续原任务”。普通上传不会绕过已有的阻塞、未确认或完成记录；确实需要另一份时，通过“确认另建一份上传”明确操作。不同账号、平台和视频分别识别。

小红书创作者页面明确提示草稿存于当前浏览器本地，清理浏览器数据会移除它；抖音的暂存提供“继续编辑”；B站可保存带身份的文章草稿。工作台按实际证据区分“已上传，待人工发表”和“平台草稿已保存”。

## 作品与数据

每份发布内容保留独立上传记录。发表后关联准确的作品ID或链接，再同步阅读、播放、点赞等实际可取得的数据。同平台多份作品分别记录；标题只用于候选排序。同步失败保留上次成功数据，未知值显示为未知。

B站回收同时读取视频与图文管理。一次同步中的同平台、同账号作品共用一次读取，匹配全部目标作品后结束；每个平台最多执行180秒，可取消。

## 文件与凭据

正文、图片和视频保留在项目目录。移除条目沿用文件保留规则。旧数据首次写入新格式前备份，发布材料采用版本检查和原子保存。

生图仍使用设置中的地址、模型及宿主保存的Key；聊天和看图使用Harness当前Agent。凭据不进入提示词、普通任务记录或安装包。
