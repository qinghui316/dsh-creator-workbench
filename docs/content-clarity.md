# 内容与操作

工作台保留原生对话、项目列表和七个页签。概览展示实际视频、文章配图、正文摘录、项目图片、三种当前封面与具体发布内容；对应操作打开展示的那一项成果。空模块是一行入口。

图片按实际内容容器排列：不足400px一列，400px起两列，680px起三列。图片保持比例，名称来自已有文件。点击图片只打开中央预览；选用、排序和移除仍各自明确执行。图库的尺寸、来源及路径在图片详情查看，移除在该图菜单中。

透明图片使用固定的浅色棋盘画布，深色主题下也能认清内容；画布不改变原图。打开图库详情时，只滚动项目内容区使详情可见，返回后恢复原来的位置和操作焦点。

文章阅读、编辑、AI修改和去发布保持直接可达；新建、视频转文章和导入集中在新建文章菜单。HTML文件入口在更多菜单。发布页按当前材料、文案与素材、上传结果及作品组织，材料移除位于材料操作菜单，以前的作品通过作品记录查看。

菜单使用宿主控件和浏览器顶层能力避开滚动区裁切，键盘可遍历全部菜单项。页面滚动后关闭菜单，菜单自身滚动不关闭；关闭恢复相应焦点。后台刷新继续保护播放器、图片预览和未保存输入。

这些调整不改变工具、Remote、目录、任务、保存和提交快照。右侧准备的AI要求仍由用户在原生对话发送；平台最终发表由用户完成。项目保存位置继续独立即时生效，凭据仍由宿主服务处理。
