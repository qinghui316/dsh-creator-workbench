# 0.8.2 控件与连续动效

工作台保留项目列表与内容双栏，以及“概览、视频、脚本、字幕、文章、图片、发布”的顺序。

页签下划线随实际页面连续移动；发布平台、设置分组和文稿模式使用圆角底板。导航移动约220ms，颜色反馈约120ms。首次打开、布局重排直接落位；系统减少动态时选中立即显示。

常规输入、按钮、选择器和菜单采用12px圆角，紧凑图标按钮与选项为8px。保持宿主字体、字号和缩放。

下拉框展开后，上下键浏览、Home/End定位、首字查找，Enter或点击确认；Esc、Tab与点击外部取消本次浏览。中文输入法组合期间不截断输入。键盘高亮与当前选中标记分别表达浏览和已生效值。选择默认父目录后仍即时保存，文章和设置切换仍受未保存保护。

`SelectionRail`只测量已经接受的ARIA选中项；动画不负责切页或保存。`CreatorSelect`保持受控值并调用原处理器。选择器与`ActionMenu`共用弹层定位、退出清理和高亮测量，分别保留listbox和动作菜单的键盘语义。Portal及原生Popover使弹层不被滚动容器裁切；菜单Tab从入口所在文档位置离开。

公开Remote、Agent工具、业务类型、任务、凭据及项目数据格式沿用既有实现。SayWeave/Beaver用于行为与参数参考，本轮共享控件独立实现，未引入其框架或运行时。

自动回归见`tests/selectionControls.test.ts`、`tests/interactionControls.test.ts`和各业务UI测试；安装、连续帧和主题宽度证据由`workbench-sayweave-motion-controls` Change记录。
