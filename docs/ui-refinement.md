# 0.3.0 界面优化验证

本次 Change：creator-workbench-ui-simplification。先恢复 f8c6117 与已验收的 0.2.0 安装，再进行内部界面整理。

## 范围与结果

保留原生对话与业务分栏、业务左侧历史内容、右侧详情、全局入口位置，以及「概览 → 视频 → 脚本 → 字幕 → 文章」顺序。

- 视频仍是选文件、确认、导入，再明确选择和播放。管理、撤销和恢复放在原视频区域内。
- 封面三画幅默认显示当前结果，操作菜单打开导入与版本；放大预览、制作进度和记录都留在业务区。
- Agent 草稿、工具参数、图片附件及后台执行契约沿用 0.2.0。
- 生图地址、Key、模型在一个表单内保存。Key 经宿主凭据服务；设置更新协调只记录非敏感目标和完成状态。更新未完成时阻止新的生图启动，原运行任务继续使用快照。
- 脚本显示保存中、已保存、保存失败和重试；字幕与文章页分别保留。
