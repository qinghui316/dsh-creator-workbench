# 内容目录约定

用户选择资料库，每期内容对应一个直接子目录，新建名称为 YYYY-MM-DD_可读标题。文件是正文的真实来源。

| 文件 | 用途 |
| --- | --- |
| topic.md | 选题笔记 |
| script.md | 脚本 |
| *.mp4、*.mov（扩展名不区分大小写） | 视频候选；非空普通文件才进入候选 |
| *.srt、*.ass、*.subtitle-work/ | 可选字幕与外部 Skill 产物 |
| *_3x4.png、*_4x3.png、*_16x9.png | 已有封面展示 |
| 发布包及 auto-publish.json | 兼容上游发布材料、平台状态 |
| 公众号文章/ | 文章正文与相对图片资源 |

视频候选返回相对文件名、完整路径、字节数和修改时间。一个候选且没有历史选择时自动选中；多个候选时明确选择。修改时间只供显示，不决定上传源。
当前视频选择保存在工作台独立状态目录 overlay.json 的 videoSelections 中，以资料库 → 内容 id → 相对文件名区分，正文不进数据库。
`null` 表示主动清空，与没有保存过选择、文件已丢失区分。`hiddenVideos` 以相同资料库/内容范围保存相对文件名；扫描仍核对磁盘，恢复缺失文件会报告失败。整理目录时同步保留当前选择和隐藏记录。

导入不会移动、删除或重命名源文件。同名目标冲突需要修改导入名称后重试。临时文件为 .import-UUID.partial；应用中断留下的临时文件不会进入片库。本阶段不自动接管或删除历史临时文件。

封面保存在本期 `.dsh-creator-workbench/covers/`：`index.json` 保存制作记录、逐画幅结果、版本、质检和当前选择；`runs/<UUID>/` 保存候选画面、分析、方案和逐画幅提示词；`versions/<UUID>/cover.*` 保存不可覆盖的图片。索引采用原子写入，完整产物优先保留。中断后依据已预留的版本身份与真实文件对账，不依靠 PID 或自动重发。

已有 `_3x4.png`、`_4x3.png`、`_16x9.png` 兼容识别。明确选择的新版本与旧文件保持同一返回路径规则，后续发布需使用该选择。图片比例不符不会暗中拉伸或裁切。

生图非敏感配置位于工作台自身状态目录 `image-service.json`。凭据仅在 Harness 凭据服务中保存，不进入本期资料或此配置文件。
