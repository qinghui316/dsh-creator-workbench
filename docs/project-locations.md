# 项目与保存位置

一个项目对应一个文件夹。工作台汇总已经创建、明确加入及能够核实来源的项目；默认父目录只决定新项目存放位置。

## 日常操作

- 数据与设置 → 常规 → 项目保存位置：选择已有父目录，或选择其他位置。选择后立即生效，无需点击保存。其他正在编辑的设置继续单独保存。
- 新建项目：填写项目名称，选择“保存到”，核对预计路径后创建。工作台沿用日期加标题；同名时编号，不覆盖文件。本次位置不改变默认位置。
- 使用已有目录：所选文件夹直接加入项目列表，名称、文件和位置保持。可以加入其他盘符、网络位置、空目录或可读的只读目录；实际写入按权限反馈。
- 切换默认位置后，其他位置的项目和当前详情继续保留。同名项目可通过标题的完整路径提示区分，搜索也支持位置。
- 目录离线时保留条目，显示暂不可访问；不会当成空项目或自动创建替代目录。
- 移除保留原文件并阻止自动发现或旧会话恢复。以后通过使用已有目录明确重新加入。

## Agent 与会话

creator_list_projects 返回跨位置列表、稳定编号和准确目录。creator_create_content 在明确父目录或已保存默认位置中创建日期项目；requestId 用于通信重试。creator_add_project 直接加入已有目录，creator_set_default_parent 只改变默认新建位置。

其他创作操作继续共用同一业务层。旧名称编号可在唯一时兼容；存在同名项目时同时传 folderPath。打开项目对话复用准确目录下的原会话；恢复会话不会更换默认父目录。历史会话线索在后台核实，当前会话只等待自己的目录；查询不创建工作区或发送草稿。

## 数据与兼容

projects.json 保存父目录、默认位置、项目身份、路径别名、移除屏障及项目级选择；overlay.json 保留全局偏好。媒体、正文、生产任务及发布快照仍在项目原目录。

首次迁移保留旧 overlay 原文备份，合并可准确对应目录的选择和移除状态。仅有旧名称、没有目录依据的标题或手动发布状态保存在 legacyItems 和备份中，不分配给可能同名的另一项目。没有记录、没有产物和会话线索的旧空文件夹，可明确加入。

发现只检查已保存父目录的一级候选和有效工作台标记。普通视频、日期名称或一般文件夹不会自动加入。监听仅覆盖项目根目录、实际使用的工作台目录及已知资源的元信息；不递归扫描素材树。读取损坏登记时停止并提示保留文件，不覆盖为空列表。

整理文件夹须明确父目录，先预览，再按用户确认的范围执行；运行或待核对任务、包含另一个已登记项目的目录需先处理。目录移动或链接目标变化不自动重定向既有任务。
