# 删除、封面状态与数据同步：0.4.1

Change：`creator-workbench-state-ux`。保留原生对话、历史侧栏和右侧详情，以及概览、视频、脚本、字幕、文章的顺序。

## 项目和资源

删除项目时先确认范围。有任务时明确取消；相关工作台会话归档，只有全部属于本项目的空工作区才注销。共享或其他会话保持完整。目录、文件和历史保留，界面不显示回收列表。需要时在“新建内容 → 使用已有目录”重新加入，并优先恢复已有会话。

视频和封面移除只改变工作台显示，文件保留。当前项移除后保持空选择；扫描与迟到结果不会自动补选。重新导入可再次加入。

## 封面

三画幅结果、选用状态与当前制作请求分别展示。各画幅显示选用状态；正在处理的请求显示进度，历史记录可从详情查看。重新制作仍由用户在原生会话发送，先检查会话和草稿再建立请求；插入失败只清理本次新建的未启动记录。

## 发布与同步

发布状态、指标和“同步数据”在同一区域直接显示。上传材料、作品关联及任务详情按需打开。同步先返回任务身份，逐平台记录结果，每个平台包含账号检查与采集的总时限为 180 秒。取消、超时、断连和用户接管均结束当前处理，不自动再次接管。

准确关联后直接读取对应作品。同账号、同作品的真实结果确认已发表，才更新发表状态。标题只排序候选，不自动匹配。失败时保留原状态和上次成功数据；未知值与零区别显示。平台账号、关联或资料位置改变后，旧结果不会写入当前内容。

后台刷新保留媒体、封面、HTML、表单和列表，不清空设置。任务日志与历史只在详情查看。公众号远端上传和视频号继续延期。

## 本轮验收

最终自动检查、安装字节和本机界面证据记录在同名 Change 的验证文档与 `.artifacts/state-ux-*`。未取得实际证据的操作仍列为待验证，安装与业务验收分别记录。
